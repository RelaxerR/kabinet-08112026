# Адвент-календарь

## Как это работает
- `gifts.source.json` — твой исходник (подарки, загадки, ответы). В git НЕ попадает (см. `.gitignore`).
- `node tools/build.mjs` шифрует подарки ответами на загадки и пишет `data.json`. Его публикуем.
- Подарок физически зашифрован ответом: без верного ответа его не прочитать даже из исходников страницы.
- В 18:00 МСК открывается загадка, после верного ответа подарок показывается в 18:30 МСК.
- 8 ноября после открытия подарка запускается эффект с сердечками.

## Что заполнить
В `gifts.source.json` замени все «ЗАМЕНИ»:
- `greeting`, `riddle`, `hint` (необязательно);
- `answers` — список допустимых ответов (регистр, «ё/е», пробелы и знаки не важны; добавляй синонимы);
- `gifts` — подарки дня (2 подарка можно положить в один день, у тебя 9 подарков на 7 дней);
- для 8 ноября ещё `finalMessage`.

Потом: `node tools/build.mjs`.

## Тест локально
```
python3 -m http.server 8000
```
Открой в браузере и подставь «фейковое» время:
- http://localhost:8000/?now=2026-11-02T18:05:00%2B03:00 — загадка первого дня
- http://localhost:8000/?now=2026-11-08T18:40:00%2B03:00 — финал (после ввода ответа)

Ответ-заглушка везде: `тест`.

## Перед публикацией
1. В `app.js` поставь `DEBUG_ENABLED = false` (иначе `?now=` позволит подсмотреть будущее).
2. Замени ответы-заглушки на настоящие и пересобери `data.json`.
3. Запушь в репозиторий (без `gifts.source.json`), включи GitHub Pages (Settings → Pages → Deploy from branch).
4. Проверь страницу в приватной вкладке.
